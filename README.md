# 🃏 Advanced Blackjack (C++ Console Game)

Welcome to **Blackjack**, an interactive C++ console-based game where you play against a virtual dealer. Enjoy a classic game of 21 with added strategy, double-down options, betting, and polished terminal output.

---

## 🎮 Features

- ✅ 52-card deck with shuffling
- 🃏 Face cards and Ace logic (1 or 11)
- 💰 Betting system with player chips
- 🔁 Continuous rounds until chips run out
- 🎯 Double Down option (only on first move)
- 🎨 Colored console output (Red = Bust/Loss, Green = Win)
- 🧠 Dealer logic: hits until 17+

---
